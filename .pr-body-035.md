## Summary

- **`MagicLinkPage`** — async Server Component at `/magic-link/[token]`:
  - Fetches `GET /api/magic-links/[token]` server-side (no-store cache)
  - 410 → `ExpiredView` (link expired, option to contact studio)
  - Other errors → `ErrorView`
  - 200 → `AppointmentManager` with appointment data
- **`AppointmentManager`** — `"use client"` multi-view state machine:
  - **Detail view**: shows appointment card (type, date/time, status) + action buttons for CONFIRMED appointments
  - **Cancel flow**: inline confirmation panel → `POST /api/appointments/:id/cancel` → success or error message
  - **Reschedule flow**: native date input → `useEffect` fetches `/api/availability` → slot grid → `POST /api/appointments/:id/reschedule { newStartAt }` → success or error message
  - Loading states on all async actions; graceful error display with back navigation
