## Summary

- **`CalendarPublic`**: monthly grid component (Monday-based) with available/unavailable/selected/today day states, prev/next month navigation, dot indicator on available days
- **`SlotPicker`**: TanStack Query-powered component that fetches `/api/availability` for a given date, with loading skeleton, empty state, and error state
- **`bookingApi.getAvailability`**: typed `fetch` wrapper — takes `from`/`to` Date objects, returns `TimeSlot[]`
- **`QueryProvider`**: app-wide `QueryClientProvider` wrapper (staleTime 60s, retry 1)
- **Bug fix**: CalendarPublic used `toISOString().slice(0,10)` for local date cells, which breaks in non-UTC timezones. Replaced with explicit local date string formatting.
